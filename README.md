# peppapigmousekeyboard

## Publish on GitHub Pages

The generated app is not yet in this repository. If it is a static HTML app, you
can publish it entirely through the GitHub website:

1. Open this repository on GitHub and select the `main` branch.
2. Select **Add file** > **Create new file**, name it `index.html`, and paste
   the HTML generated by Gemini. Commit it to `main` (or create a branch and
   merge the resulting pull request into `main`).
   Alternatively, use **Add file** > **Upload files** if you already have the
   file. Upload any separate CSS, JavaScript, images, or other assets it needs,
   preserving their paths.
3. Open **Settings** > **Pages**. Under **Build and deployment**, choose
   **Deploy from a branch**, select `main` and `/(root)`, and click **Save**.
4. Wait for the deployment to finish, then visit
   https://jrookpanda.github.io/peppapigmousekeyboard/. The Pages settings page
   also shows the site URL. Future commits to `main` will update the site.

Use relative paths such as `./style.css` rather than `/style.css`, since this
site is hosted under `/peppapigmousekeyboard/`. GitHub Pages serves static files
only; an app requiring a server or a build step needs additional hosting or
build configuration. Never put API keys or other secrets in the HTML or other
files published to Pages: visitors can read them.

If the site does not appear, check the deployment under the repository's
**Actions** tab and see GitHub's
[Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
