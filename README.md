# 🐷 Peppa's Mouse & Keyboard Star Kit

A colorful, toddler-friendly browser game designed to help young children learn real computer skills through play.

Players join Peppa Pig and friends to collect stars, race to Muddy Castle, and practice mouse and keyboard skills in a safe, positive, and encouraging environment.

---

## 💖 For Stella

This game was created especially for Stella.

I wanted her first experiences with a computer to be fun, positive, and full of encouragement. Every click, every star, every celebration, every muddy puddle, and every playful challenge was designed to help her learn real mouse and keyboard skills while enjoying adventures alongside her favorite characters.

The goal was never simply to build a game.

It was to create a joyful first step into the digital world, where curiosity is rewarded, mistakes are harmless, and learning feels like play.

One day she'll outgrow muddy puddles and star races, but I hope she'll always remember that her very first computer game was built just for her.

Made with love, patience, and countless smiles for Stella. ❤️✨

— Dad
